# WhatIfAI AI Agents

## Overview

WhatIfAI uses 6 specialized AI agents orchestrated through Lamatic Flows:

1. **Business Data Agent** - Validate and normalize business input data
2. **Digital Twin Agent** - Create an AI model of the business
3. **Simulation Agent** - Process what-if scenarios
4. **Forecast Agent** - Generate time-based predictions
5. **Strategy Agent** - Recommend optimal business strategies
6. **Report Agent** - Generate comprehensive reports

## Flow Pipeline

Business Data → Digital Twin → Simulation → Forecast → Strategy → Report
