# WhatIfAI API Documentation

## Endpoints

### Business
- `POST /api/business/create` - Create business
- `GET /api/business/get` - Get business data
- `PUT /api/business/update` - Update business

### Simulation
- `POST /api/simulation/create` - Run simulation
- `GET /api/simulation/get` - Get results

### Forecast
- `POST /api/forecast/predict` - Generate forecast

### Report
- `POST /api/report/generate` - Generate report

### Agents
- `POST /api/agents/business-data` - Business Data Agent
- `POST /api/agents/digital-twin` - Digital Twin Agent
- `POST /api/agents/simulation` - Simulation Agent
- `POST /api/agents/forecast` - Forecast Agent
- `POST /api/agents/strategy` - Strategy Agent
- `POST /api/agents/report` - Report Agent
